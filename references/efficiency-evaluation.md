# 效率系统：时间是否转化为可验证表现

用户问“我最近学得有没有用”“明明很忙为什么没进步”，或做周复盘时运行 `efficiency --days 7`；`report` 保留原始记录，`efficiency` 给一个**可推翻的诊断**。不生成综合效率分。

| 维度 | 引擎实际显示 | 读法 |
|---|---|---|
| 执行 | 计划任务、完成任务、完成比例与实际分钟 | 比例低先检查任务是否超出现实容量 |
| 有效证据 | 已核验来源题、原创题、写译有证据反馈、限时模考、无核验作答分别计数 | 只看材料和完成打卡不等于独立能力 |
| 独立作答 | 听读已核验题与原创题分别显示每题**首次作答**的原始正确数/题数；重做原题单列 | 不把记住同一题的答案当作新题能力，也不跨来源、难度或题型拼成“提分” |
| 错因复发 | 同一错因标签重复出现的次数 | 先修一个可定位机制，不堆更多题 |
| 检查点转化 | 同题型、同题数且时长相近的两次模考原始正确率 | 试卷难度未必相同；不能换算官方报道分 |

## 诊断顺序

这些阈值只是**本地行动触发器**，不是心理测量或考试预测：无足够记录 → 至少 3 项任务的完成比例低于 60% → 已打卡但没有独立输出 → 至少 5 道已核验来源题的原始正确率低于 50% → 错因复发 → 已做至少 5 道来源题却缺限时检查点 → 保持当前闭环。每次只处理排在最前面的上游问题。

将结果翻译成“证据—可能原因—下周只改一步”。先让学生说自己看到什么，再补充被忽视的数据；不要把低执行率解释成人格缺陷，也不要把一次模考波动解释成趋势。计划属于假设，练习记录和限时结果负责检验它。[形成性评价](https://doi.org/10.1080/0969595980050102)与[自我调节学习](https://doi.org/10.1207/s15430421tip4102_2)提供方法背景，但当前少量本地记录仍有题目难度、未记录行为和考试状态等限制。

### 一次反馈的最小格式

```text
最近 7 天完成 2/5 项计划任务，且没有限时检查点。
当前先处理容量失真：明天只留一组 20 分钟阅读定位题。
完成证据：写下原始正确数、用时和一个最迷惑的干扰项。
```
