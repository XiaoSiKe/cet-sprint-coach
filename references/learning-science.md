# 学习科学：把方法落实到四六级训练

学习方法是可试验的工具，不是提分承诺。优先选能产生**独立作答证据**的方法；学生的基础、材料质量和考试时限决定实际安排。

| 当前任务 | 首选做法 | 完成证据 |
|---|---|---|
| 单词与搭配 | 看语境 → 遮住释义提取 → 造一个新句 → 到期再提取 | 无提示说出意义、搭配与用法；下次仍能提取 |
| 听力 | 先听作答 → 定位没听出的短片段 → 对照脚本 → 换音频复测 | 不看脚本时答对同类信息点；记录音频与用时 |
| 阅读 | 限时定位 → 写出支持句 → 解释最像的干扰项错在哪里 | 新篇章中能独立定位和排除，而非背住原题 |
| 写作 | 闭卷列提纲 → 限时成文 → 对照具体反馈 → 重写一段 | 新题中仍能组织论点并减少同类错误 |
| 翻译 | 先译出信息点 → 核遗漏和误译 → 修句法搭配 → 换主题迁移 | 新段落能完整、自然地表达核心信息 |

## 六个方法及其边界

1. **先提取，再补充。** 看完材料后先让学生回忆或作答，再展示解释。练习测试对延迟保持通常优于单纯重读；这并不意味着每道题都应在完全没学过时硬猜。[Roediger & Karpicke, 2006](https://doi.org/10.1111/j.1467-9280.2006.01693.x)；[Dunlosky 等, 2013](https://doi.org/10.1177/1529100612453266)。
2. **把成功提取分散到多天。** 词汇卡使用本地 FSRS；刚学会的内容先做短时成功提取，后续按到期日复习。考试日前的实际可用天数优先于长期算法；复习调度不是对个人遗忘率的精确测量。[Cepeda 等, 2006](https://digitalcommons.usf.edu/psy_facpub/1771/)；[Py-FSRS](https://github.com/open-spaced-repetition/py-fsrs)。
3. **反馈只修决定性缺口。** 错因先分为信息未听出、词义/搭配、定位、推断、干扰项、表达和时间压力；补最短解释后用新题复测。反复机械刷同一题只会提高熟悉感。与有目标、有反馈的练习思想相符，但不把练习时长等同于效果。[Ericsson 等, 1993](https://doi.org/10.1037/0033-295X.100.3.363)。
4. **从支架走向独立。** 连续失败时先看一个完整示例，再让学生补关键一步，最后独立完成新题；一次只解决一个卡点。初学者的信息负荷与熟练者不同，不强迫同一训练强度。[Sweller, 1988](https://doi.org/10.1207/s15516709cog1202_4)。
5. **能辨别时才混合。** 刚接触题型可先做少量同型练习；已会基本步骤后再混合选词、匹配、仔细阅读或不同听力信息点，训练“先辨别任务再作答”。混合练习是否有用仍由新题和限时表现判断。[Dunlosky 等, 2013](https://doi.org/10.1177/1529100612453266)。
6. **让学生参与计划与复盘。** 周初写出可控制的行为目标，执行中记录首个卡点，周末先请学生解释证据再调整。启动困难时把计划写成“某节课后到图书馆，先做五分钟听力定位”的具体情境与动作。[Zimmerman, 2002](https://doi.org/10.1207/s15430421tip4102_2)；[Gollwitzer, 1999](https://www.socmot.uni-konstanz.de/publications/implementation-intentions-strong-effects-simple-plans)。

## 避免方法崇拜

- “看懂解析”“听熟原音”“背熟范文”只说明接触过；同型新题或迁移输出才说明训练发生。
- 不把群体研究变成对个人分数的预测，也不宣称固定间隔或某一套题量适合所有人。
- 写作、翻译、听力发音等有不同质量维度；词汇卡的调度结果不能替代限时整卷或真实语篇表现。
- 当错误集中在疲劳、听力设备、资料失真或计划超量时，先修条件，别把问题都归为意志力。
