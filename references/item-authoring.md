# 原创题生成与答案核验协议

“生成正确”意味着先建立可以检查的题目与证据，再让学生作答；不能保证模型从不犯错。任何无法确认唯一最佳答案的题目都标 `unverified`，不据此断言学生掌握或预测报道分。

## 出题顺序

1. 先定级别、模块、题型和训练目标。四级新闻与六级讲座不可混用；完整模拟才按[官方笔试结构](official-rules.md)安排题量与时限，微练习明确标为原创辅助训练。
2. 独立写出阅读材料或听力脚本，再写**一道**问题、四个 A–D 选项和唯一最佳答案。听力脚本单独存入 `transcript`，必须先有可播放音频才能进行听力测验。
3. 不看草拟答案，回到原文重新求解；摘出能直接支持正确项的原文短句存入 `evidence`。逐一说明其余选项究竟错在主体、范围、时间、因果、态度或过度推断。两个选项都合理时重写题目。
4. 检查选项是否完整、互不重复，正确项是否真的来自证据，题干有没有泄露答案，材料与题型是否符合级别。程序会拦截明显的结构与引文错误；它不能证明语义唯一，必须再由教练审读。
5. 通过 `material item-add` 或 `batch-add` 入库，使用 `source_type=original` 和 `answer_status=generated`。作答前只展示题干/音频；作答后才给参考答案与依据。原创题只用于练习，不冒充官方真题或分数预测。

## 主观题

- 写作和翻译先给原题，让学生独立写/译。反馈引用具体学生原句，区分任务完成、信息准确、结构、词汇搭配和语法；只修最影响理解的少数问题，再让学生重写。
- 参考作文或译文是可能的表达，不是唯一标准答案。没有原题、作品或可靠评分规则时不给精确分；任何模型估计必须写“非官方教练参考”。
- 不因复杂词或长句自动加分，不把事实错误误判成语法错误。

## 引擎能检查什么

对于单选题，`quality.py` 要求 A–D 四个不同的完整选项；有答案时只能是 A–D；题干不得含显式答案标记。原创阅读/听力若标 `generated`，必须提供能在材料或听力脚本中逐字找到的证据短句，原创听力还须有脚本。`item-update` 与批量导入使用同一个校验入口。

机器检查不能发现所有歧义、常识性错误或过时信息。教练若对证据仍存疑，应撤下该题或改为 `unverified`，并使用可核验来源题校准主攻判断。
