# 哲学工具：把冲刺计划当成可检验的判断

这里借用思想方法来做学习决策，不扮演人物，不以名言或口号代替事实。

```text
调查现状 → 提出主攻假设 → 集中有限时间 → 用新题检验 → 校正 → 随阶段重排
```

| 思想工具 | 四六级中的具体用法 | 失效边界 |
|---|---|---|
| 调查与主要矛盾 | 核考试日期、真实时间、题型分布、限时结果；本周只选一个最限制进展的错因或模块 | 一套题或一次自评不足以宣布“听力天生差”；仍给其他模块最低维持量 |
| 实践检验与反思 | 把“精听能修数字题”写成假设，下一组不同音频测数字识别；无变化就改方法或重新定位错因 | 反复播放原音频的熟悉感不能当迁移 |
| 控制边界 | 报道分和试卷难度不由学生立即控制；今天是否睡够、是否按时做一组限时题、是否记录错因可控制 | 不把学校安排、健康或经济约束说成“心态问题” |
| 阶段性取舍 | 考前优先练仍有可改变空间、且能在真实时限完成的任务 | 无官方范围或可靠分布证据时，不把低优先级说成“不会考” |

这些分别呼应[《实践论》](https://www.marxists.org/reference/archive/mao/selected-works/sw-from-lw/mao-sw-lw-v1.pdf)与[《矛盾论》](https://www.marxists.org/reference/archive/mao/selected-works/volume-1/mswv1_17.htm)中的调查、矛盾和实践方法，[杜威《我们如何思维》](https://www.gutenberg.org/ebooks/37423)中的反思性探究，以及[爱比克泰德《手册》](https://classics.mit.edu/Epictetus/epicench.html)中的控制范围区分。本 Skill 只把它们译成学习决策工具，不把哲学文本当作考试科学证据。

## 主攻判断的记录方式

1. **事实**：例如六级长对话近两次限时练习共错 6/16，主要是转折后信息未识别。
2. **暂定解释**：学生知道词义，但听到转折时没有更新预期。
3. **本周动作**：只练转折后的证据定位，同时维持阅读与词汇最低量。
4. **反证条件**：两次不同来源音频仍无改善，或其他模块的真实缺口明显更大时重判主攻。

不要因为一次单题失误每天改战略；也不要因为“计划已定”拒绝新的同口径检查点。学科权重、错因复发和现实容量一起决定优先级，内部启发式不能描述成精确提分概率。
